ComeMorocco AI

Widget preview. The launcher is in the bottom-right corner.

This page exists to review the widget against a real backend. Start the API with make run, then reload. Without a running API the panel opens and the interface works, but answers will fall back to the error state.

What to check

  • Answers stream in rather than appearing all at once.
  • Resource cards appear only when a page is genuinely relevant.
  • Affiliate cards carry the partner label, and do not appear on questions like “what should I see in Marrakech?”
  • Follow-ups keep context: ask about a 10-day trip, then just say “actually, add Essaouira”.
  • Keyboard only: Tab to the launcher, Enter to open, Esc to close.
  • Narrow the window below 480px for the mobile layout.

Embedding it elsewhere

<script
  src="/widget/comemorocco-ai.js"
  data-api-base="https://ai.comemorocco.com"
  data-widget-key="YOUR_KEY"
  data-locale="en"
  defer></script>

On WordPress, install the plugin in wordpress-plugin/ instead — it handles the key, locale and per-page rules from the admin screen.
