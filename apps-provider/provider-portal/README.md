# ComeMorocco Provider Portal (planned)

provider.comemorocco.com — Master Plan §27, Phase 8. Not part of Foundation v0.1.

Providers manage profile, listings, pricing, availability, booking requests, customers,
commission, payouts, analytics, notifications and documents. Isolation between providers is
enforced by RLS (`is_provider_member`) — see `supabase/migrations/*_rls.sql`.
