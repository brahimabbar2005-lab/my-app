# ComeMorocco Admin (planned)

Internal operations console — Master Plan §45. Not part of Foundation v0.1.

Sections: Dashboard, Users, Destinations, Listings, Providers, Bookings, Affiliate, Community,
Reports (moderation queue), AI (provider health from `GET /api/admin/providers`, flagged answers,
content gaps), Content, Analytics, Settings. Every admin action writes `audit_log`.

Community posting in the app stays disabled until the moderation queue here exists (§29, §60.15).
